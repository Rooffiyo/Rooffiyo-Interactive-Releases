# Rooffiyo Interactive — Official Downloads

This public repository is the **release channel only** for Rooffiyo Interactive. The application source remains in a separate private repository.

**No release has been published yet.** Do not download or run files pretending to be an official release unless listed under [Releases](https://github.com/Rooffiyo/Rooffiyo-Interactive-Releases/releases) and confirmed by the project owner.

Future versions will be published as Windows ZIP packages with version notes and integrity verification. GitHub repository visibility allows others to download releases, but does not grant permission to modify or publish official versions.

Never upload Bloom.host API keys, local settings, saved queue files, streaming session tokens, or personal credentials here.
